# Teknologi Keamanan Siber - Algoritma Dasar Kriptografi

Implementasi Caesar, Vigenere, Substitution, Transposition, dan
Playfair dalam Python, dilengkapi web visualisasi langkah demi langkah.

## Anggota

Dion, Keihan, Hery, Dhyty, dan Rakhman.

## Demo

[Buka visualisasi](https://tks-kriptografi-b920186fe783.herokuapp.com/)

## Kode

Implementasi setiap algoritma tersedia secara mandiri di folder
[algorithms](algorithms/).

Contoh menjalankan Caesar: `python3 algorithms/Caesar/main.py`

Dibuat untuk pembelajaran, bukan untuk mengamankan data nyata.
